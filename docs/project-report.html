Backend (FastAPI + NumPy)

Network implementation

  • Dense layers with weight matrices (n_in, n_out) and bias rows; vectorised over the batch (no per-sample loops).
  • Sigmoid (overflow-free), tanh, ReLU with derivatives expressed via cached z/a.
  • BCE computed from logits: max(z,0) − z·y + log1p(exp(−|z|)); output error (p−y)/m.
  • SGD and Adam (bias-corrected); Xavier / He / small-normal / zeros initializers; seeded everywhere.

Sessions

Each experiment owns its data split, network, optimizer, RNG, history, lock and worker thread. Pause is a threading.Event checked before every mini-batch; reset stops the worker and re-initialises from the seed. A janitor removes idle sessions after the TTL; creation beyond the cap evicts the least recently used.

Visuals

Decision boundary on Canvas (heat-map + marching-squares contour, pan/zoom, keyboard). Network diagram in SVG from real parameters. Recharts for analytics. KaTeX for formulas.
